# Корпоративный портал АО «Казанский Гипронииавиапром»

Корпоративный портал для внутреннего использования предприятия. Предоставляет единую точку входа для новостей, сервисов, сетевых ресурсов и коммуникации сотрудников.

---

## 📋 Основные возможности

### 🔐 Аутентификация через Active Directory
- Единый вход с доменными учётными записями
- JWT-токены для сессий
- Интеграция с LDAP/AD

### 📰 Новости предприятия
- Публикация новостей с поддержкой галерей изображений
- Категории новостей (объявления, технические, мероприятия, важное)
- Редактирование и удаление (для администраторов и модераторов)

### 📅 Календарь событий
- Планирование встреч, ВКС, задач
- Приглашение участников (пользователи и AD группы)
- Напоминания по email и через тост-уведомления
- Повторяющиеся события
- Три режима просмотра: месяц, неделя, день
- Группы для массовых рассылок

### 🔗 Сервисы
- Централизованный доступ к корпоративным веб-сервисам
- Настройка прав доступа (для всех / для конкретных групп/пользователей)
- Иконки и сортировка

### 📁 Сетевые ресурсы
- Каталог сетевых папок с копированием путей
- Иерархическая структура категорий и ресурсов
- Наследование прав доступа от категорий

### 👥 Управление пользователями
- Назначение ролей:
  - ⚙️ **Администратор** — полный доступ
  - 👑 **Начальник отдела** — управление заменами
  - 🛡️ **Модератор** — управление новостями
  - 🔧 **IT-инженер** — управление IT-задачами и комплектующими
  - 👤 **Пользователь** — базовый доступ

### 💬 Чат
- Встроенный Rocket.Chat для коммуникации
- Открывается в отдельном окне

### 📝 Заметки
- Личные заметки пользователей
- Сохраняются в localStorage

### 🔄 Замены на отпуск
- Информация о временных замещениях сотрудников
- Управление доступно администраторам и начальникам отделов

### 📢 Оповещения
- Система уведомлений для всех пользователей
- Администраторы могут создавать и удалять оповещения
- Автоматические уведомления о событиях календаря

### 🛠️ IT-задачи
- Учёт и контроль выполнения задач IT-отдела
- **Сортировка по сроку выполнения** (ближайшие сверху)
- **Индикатор срочности** (просрочено / скоро)
- Категории задач (Сборка ПК, Ремонт, Принтеры/МФУ)
- Статус комплектующих (есть / не полный / нет)
- Архивация выполненных задач
- Экспорт отчёта в Excel
- **Мониторинг задач** (только для администраторов):
  - Статистика по сотрудникам
  - Фильтрация по статусу и датам
  - Ручное добавление сотрудников для мониторинга

### 🔧 Периодические задачи
- Автоматическое создание задач по расписанию
- Настройка интервала (дни)
- Возможность запуска вручную

### 🖥️ Комплектующие
- Учёт типов комплектующих для IT-задач
- Категории: комплектующие ПК, расходники принтеров, сетевое оборудование

### 🌓 Тёмная тема
- Полная поддержка светлой и тёмной темы
- Переключение через кнопку в шапке
- Сохранение выбранной темы в localStorage
- Адаптированы все разделы портала

### 📊 Мониторинг IT-задач (Admin only)
- Статистика по сотрудникам
- Задачи в срок / не в срок
- Просроченные задачи
- Экспорт в CSV

## 🏗️ Технологии

### Бэкенд
| Технология | Назначение |
|------------|------------|
| Python 3.10+ | Язык программирования |
| FastAPI | Веб-фреймворк |
| SQLite | Базы данных (settings.db, news.db, chat.db) |
| JWT | Аутентификация и токены |
| LDAP/AD | Интеграция с Active Directory |
| SMTP | Почтовые уведомления |

### Фронтенд
| Технология | Назначение |
|------------|------------|
| React 18 | Пользовательский интерфейс |
| Vite | Сборка и разработка |
| Lucide React | Иконки |
| React DatePicker | Выбор дат |
| Rocket.Chat | Встроенный чат |

### Инфраструктура
| Технология | Назначение |
|------------|------------|
| Uvicorn | ASGI сервер |
| Git | Контроль версий |
| Systemd | Управление сервисами |
| Nginx | Прокси и статика |

## 🚫 Файлы, исключённые из репозитория

| Файл/папка | Причина |
|------------|---------|
| `backend/.env` | Секретные ключи и пароли |
| `backend/*.db` | Базы данных (чат, новости, настройки) |
| `backend/uploads/` | Пользовательские файлы |
| `backend/__pycache__/` | Python кэш |
| `frontend/node_modules/` | Зависимости фронтенда |
| `frontend/dist/` | Сборка фронтенда |
| `backups/` | Архивы резервного копирования |
| `backend/server/ad_users.py_hiden` | Конфигурация AD с паролями |
